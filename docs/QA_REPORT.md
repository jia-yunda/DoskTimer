## 4. 缺陷记录（测试期间发现并修复）

| 编号 | 严重度 | 缺陷描述 | 修复方式 | 状态 |
|------|--------|----------|----------|------|
| DEF-001 | 中 | 圆角未生效：圆角矩形外扩 6px，整窗被面板填充 | 圆角矩形改为贴合窗口边界 | ✅ 已修复并回归 |
| DEF-002 | 中 | 左侧镂空条：`smooth=True` 样条使左直边弯折约 18px | 改用密集多边形（`smooth=False`） | ✅ 已修复并回归（TC-21） |
| DEF-003 | 高 | 主窗口未设置 `-transparentcolor`，圆角实为不透明 | `apply_theme()` 补设透明键色 | ✅ 已修复并回归（TC-19） |

**打包阶段注意事项（已解决）：**
- onefile 模式下 `__file__` 指向临时解压目录 → 通过 `sys.frozen` 分支将 config 指向 exe 目录（TC-18 验证）；
- PyInstaller 6.22.2 的 Scripts 目录不在 PATH → 用 `python -m PyInstaller` 调用；
- 强制杀父进程会残留子进程持有互斥锁 → 测试用 `taskkill /T /F` 杀进程树（TC-16）。

**环境性事项（非产品缺陷）：**
- 自动化截屏受桌面壁纸动态变化干扰，before/after 差分不可靠 → 改用红底背景 + 定点像素比对；
- PowerShell 截屏与 Python 窗口坐标存在 DPI 上下文差异 → 用应用自身 DBG 输出定位窗口。

## 5. 风险评估

| 风险 | 等级 | 说明与缓解 |
|------|------|------------|
| 仅支持 Windows | 低 | 按需求即为 Windows 程序；跨平台需替换 winsound 与透明窗口实现 |
| 杀进程残留 | 低 | 正常右键退出/关闭均无残留；仅强制 taskkill 父进程时可能出现孤儿，已在测试中规避 |
| `-transparentcolor` 依赖 Windows 实现 | 低 | 目标平台固定 Windows，真机验证通过 |
| 高分屏多显示器 | 中 | 内置 DPI 感知；多显示器默认定位主屏，拖动后位置记忆正常 |
| exe 体积（12MB） | 低 | onefile 单文件换取零依赖便携，可接受 |
