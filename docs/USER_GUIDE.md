# DeskTimer 使用手册（USER GUIDE）

> 文档版本：1.1 ｜ 适用版本：DeskTimer 1.1（含 exe 打包）｜ 更新日期：2026-08-23

## 1. 环境要求

| 运行方式 | 要求 |
|----------|------|
| **exe 方式（推荐）** | 无需安装任何东西，Windows 10/11 双击即用 |
| **源码方式** | Python 3.8+（内置 tkinter），Windows 10/11 |

## 2. 安装与启动

### 2.1 直接双击 exe（推荐）
```
e:\Code\DeskTimer\dist\DeskTimer.exe
```
- **单文件**，无需安装 Python；
- **单实例**：重复双击不会打开第二个窗口（已运行时第二次点击无反应）；
- 主题与窗口位置自动保存在 exe 同目录的 `config.json`。

### 2.2 源码运行
```bash
cd e:\Code\DeskTimer
python main.py
```

### 2.3 开机自启（可选）
- `Win + R` 输入 `shell:startup` 回车，把 `DeskTimer.exe` 的快捷方式放入。

## 3. 界面说明

悬浮在屏幕右上角的半透明圆角小组件（默认 380×172）：

```
┌────────────────────────────────────────────┐
│  时钟                        [⇄ 模式]      │  ← 顶栏：当前模式 + 切换按钮
│               22:14:36                    │  ← 大字时间（三种模式共用）
│       2026-08-23 · 星期六                 │  ← 副标题（日期/状态提示）
│  [1分][3分][5分][10分][25分][05:00][开始] │  ← 底部控制区（随模式变化）
│                         [重置]            │
└────────────────────────────────────────────┘
```

- 窗口**无边框**，按住空白处可**拖动**；
- 右键菜单：**切换主题 / 复位窗口位置 / 退出**。

## 4. 模式与操作

### 4.1 模式切换
- 点击右上角 **「⇄ 模式」** 或按 **`M`**：**时钟 → 秒表 → 倒计时 → 时钟 → …**

### 4.2 时钟模式
- 显示时间（时:分:秒）与日期（年-月-日 · 星期），无操作按钮。

### 4.3 秒表模式
| 操作 | 效果 |
|------|------|
| 点击「开始」或按 `空格` | 开始计时（按钮变为「暂停」） |
| 点击「暂停」或按 `空格` | 暂停（再按继续） |
| 点击「清零」或按 `R` | 归零 |

- 精度 0.1 秒，`MM:SS.d`；超 1 小时自动变 `H:MM:SS.d`。

### 4.4 倒计时模式
| 操作 | 效果 |
|------|------|
| 点击预设按钮（1/3/5/10/25 分） | 直接设置时长 |
| 输入框输入时长后按回车 | 设置**并立即开始** |
| 点击「开始/暂停」或按 `空格` | 开始 / 暂停 / 继续 |
| 点击「重置」或按 `R` | 恢复为设定时长 |
| 输入格式 | `MM:SS`（如 `05:00`）、`H:MM:SS`（如 `1:30:00`）、纯秒数（如 `90`） |

**到点自动触发：** 🔊 系统提示音 → ⚡ 时间大字红白闪烁约 3 秒 → 🎆 左上/右上角烟花绽放；副标题显示「时间到！」。

## 5. 快捷键汇总

| 按键 | 功能 |
|------|------|
| `M` | 切换模式 |
| `空格` | 秒表/倒计时：开始 / 暂停 |
| `R` | 秒表/倒计时：清零 / 重置 |
| `Esc` | 退出程序 |
| 输入框内回车 | 设置并开始倒计时 |

> 焦点在倒计时输入框内时，`空格`/`M`/`R` 被忽略，避免与打字冲突。

## 6. 主题与外观

| 项目 | 说明 |
|------|------|
| 主题 | 深色（默认）/ 浅色，右键菜单「切换主题」 |
| 透明度 | 0.93 整窗半透明，四角完全透明圆角 |
| 位置 | 按住拖动；右键「复位窗口位置」回到右上角 |
| 持久化 | 主题与位置自动保存到 config.json，重启恢复 |

## 7. 配置文件说明

`config.json`（与 exe / main.py 同目录，首次运行自动生成）：
```json
{ "theme": "dark", "pos": [2132, 48] }
```
- `theme`：`"dark"` 或 `"light"`；`pos`：窗口左上角坐标 `[x, y]`。
- 位置异常时删除 config.json 重启即回默认。

## 8. 打包为 exe（重新打包）

```bash
pip install pyinstaller
cd e:\Code\DeskTimer
python -m PyInstaller -F -w -n DeskTimer main.py --clean
```
产物在 `dist\DeskTimer.exe`（约 12MB）。已有现成 exe 则无需重复打包。

## 9. 常见问题（FAQ）

| 问题 | 处理 |
|------|------|
| 双击没反应 | 用命令行 `python main.py` 看报错；确认已有实例运行（单实例保护） |
| 重复双击只开一个窗口 | 正常，单实例保护生效 |
| 窗口不见了 | 右键 →「复位窗口位置」，或删除 config.json 重启 |
| 没有提示音 | 确认系统「SystemExclamation」音效未静音；有 MessageBeep 兜底 |
| 文字模糊 | 已内置 DPI 感知；仍模糊则检查系统缩放 |
| 想重新打包 | 见 §8，改源码后重新执行打包命令 |

