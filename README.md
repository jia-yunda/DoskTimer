# DeskTimer —— 简约桌面定时器

一个悬浮在桌角的半透明桌面小组件：**时钟 / 秒表 / 倒计时** 三合一，简约大方风格。

## 功能

| 模式 | 说明 |
|------|------|
| 时钟 | 显示 年月日 + 时:分:秒（星期） |
| 秒表 | 开始 / 暂停 / 继续 / 清零，精度 0.1 秒 |
| 倒计时 | 预设（1/3/5/10/25 分钟）+ 自定义输入（MM:SS），到点 **声音提醒 + 闪烁变色 + 烟花绽放**（从窗口左上/右上角绽放） |

其他特性：
- 深色 / 浅色双主题，右键菜单一键切换
- 无边框、置顶、半透明、圆角；按住窗口任意空白处可拖动
- 记住主题与窗口位置（config.json），下次启动自动恢复

## 运行

### 方式一：直接双击 exe（推荐，无需安装 Python）
```
dist\DeskTimer.exe
```
- **单文件**（约 12MB），双击即可运行，无需 Python 环境；
- **单实例保护**：重复双击不会打开第二个窗口；
- 主题与窗口位置保存在 exe 同目录的 `config.json`。

### 方式二：源码运行
```bash
python main.py
```

需要 Python 3（内置 tkinter），**Windows 系统**（使用 winsound 提示音与窗口透明特性）。

## 操作

| 操作 | 效果 |
|------|------|
| 点击右上角「⇄ 模式」或按 `M` | 切换模式：时钟 → 秒表 → 倒计时 |
| `空格` | 秒表/倒计时的开始 / 暂停 |
| `R` | 秒表/倒计时清零 / 重置 |
| 右键 | 主题切换、复位窗口位置、退出 |
| 按住窗口空白处拖动 | 移动位置 |
| 倒计时输入框回车 | 设置并开始倒计时 |

## 目录结构

```
DeskTimer/
├── main.py        # 主程序：窗口、三种模式、主题、提醒与烟花触发
├── fireworks.py   # 烟花粒子动画（透明覆盖层）
├── themes.py      # 深/浅主题配色
└── config.json    # 运行后自动生成：主题与窗口位置
```

## 打包为 exe（可选）

```bash
pip install pyinstaller
pyinstaller -F -w -n DeskTimer main.py
```

生成的 `dist\DeskTimer.exe` 可双击运行，无需安装 Python。
